# 🛍️ Интернет-магазин Aknyet (на базе БД склада)

Все новые файлы магазина вынесены отдельно в эту папку (`shop/`), чтобы процесс работы и архитектура были максимально понятны и не смешивались со старым кодом складского учета.

---

## 📂 Структура папки `shop/`

1. **`shop/shopBackend.js`** — Серверная часть магазина (подключается к `server.js` и облачной БД Turso):
   - `GET /api/shop/catalog` — отдает список товаров (`products`) и категорий (`categories`) из базы данных склада для витрины магазина.
   - `POST /api/shop/checkout` — **система оформления заказа и обновления базы данных на будущее**:
     - По умолчанию (`simulatePaymentError: true`) имитирует зависание платежного шлюза и возвращает ошибку `504 Gateway Timeout`.
     - При отключении флага имитации ошибки (`simulatePaymentError: false`) выполняет полноценную транзакцию в БД склада: проверяет остатки, вычитает купленное количество (`quantity`), увеличивает счетчик продаж (`sold_quantity`), начисляет прибыль (`realized_profit`) и добавляет запись о покупке в таблицу `history`.
   - `POST /api/shop/ai-assistant` — серверный обработчик запросов к ИИ-консультанту.

2. **`shop/services/shopApi.js`** — Клиентская логика работы с API и ИИ:
   - `fetchShopCatalog()` — загружает товары из базы данных склада (с автоматическим резервным демо-режимом, если сервер временно не запущен).
   - `processCheckoutAndDatabaseUpdate()` — пошагово проводит этапы оплаты (с зависанием на 85% и выводом ошибки) и содержит готовый вызов обновления базы данных склада.
   - `askShopAiAssistant()` — анализирует запрос покупателя (бюджет, категорию, ключевые слова, наличие) по реальным товарам из БД и возвращает рекомендации.

3. **`shop/shop.css`** — Дизайн-система по образцу сайта **https://aknyet.kz**:
   - Фирменные цвета из темы Aknyet.kz (`#43A4CF` небесно-голубой, `#FFCD24` акцентный желтый, `#F9F9FA` светлый фон, `#2E2F38` графитовый текст).
   - Оригинальные шрифты `Rubik` и `Roboto`, скругления `25px` / `16px` / `12px`.

4. **`shop/ShopApp.jsx`** — Главный компонент витрины интернет-магазина.

5. **`shop/components/`** — Модульные React-компоненты:
   - **`ShopHeader.jsx`** — верхний промо-баннер, меню, телефон/WhatsApp, логотип Aknyet, **умный живой поиск** с выпадающими результатами по товарам и категориям, индикатор корзины.
   - **`HeroBanner.jsx`** — слайдер-баннер («Освежи свой стиль, освещай свой путь») и плитки категорий с подсчетом количества товаров.
   - **`ProductCard.jsx`** — карточка товара:
     - Если `quantity > 0`: выводит название, артикул, остаток на складе, **стоимость в тенге**, выбор количества и кнопку «В корзину».
     - Если `quantity <= 0`: **вместо цены выводит «Нет в наличии»** и блокирует покупку.
   - **`ProductQuickView.jsx`** — модальное окно быстрого просмотра карточки товара.
   - **`CartModal.jsx`** — корзина покупателя, форма заказа, экран зависания и ошибки оплаты + кнопка для тестирования реального обновления БД склада.
   - **`AiAssistant.jsx`** — интерактивный чат с ИИ-помощником по выбору товаров с возможностью добавлять предложенные товары сразу в корзину.
   - **`ShopFooter.jsx`** — подвал сайта с контактами и навигацией.
